TeamOne Proxy Server Installation Guide – SSL Managed by TeamOne Proxy Server ​

This guide describes how to install the TeamOne Proxy Server when the SSL/TLS certificate is installed and managed directly on the TeamOne Proxy Server.

In this deployment model:

  • users connect to the TeamOne endpoint over HTTPS
  • the TeamOne Proxy Server manages the SSL/TLS certificate and HTTPS connection
  • TeamOne Proxy Server uses TCP port 443 as the default HTTPS listener port
  • the SSL certificate and private key are installed on the TeamOne Proxy Server
  • a load balancer may still be used in front of the TeamOne Proxy Server, provided it forwards HTTPS traffic to the server

For questions or assistance, contact teamone@succeedium.com.

Step 1: Download the TeamOne Proxy Server archive ​

Navigate to the directory where you want to install the TeamOne Proxy Server.

Download teamone-server-distr.zip using the download link provided by Succeedium.

If the target server does not have internet access, download the archive on a computer with internet access and copy it to the target server.

The downloaded file should be available as:

text
teamone-server-distr.zip

Step 2: Unzip the archive ​

bash
sudo unzip -o teamone-server-distr.zip

This creates the teamone-server-distr directory containing the TeamOne Proxy Server application, Docker images, and configuration templates.

Step 3: Create the configuration files ​

Create the TeamOne environment configuration file if it does not already exist:

bash
if [ ! -f teamone-server-distr/config/.env ]; then
  sudo cp teamone-server-distr/config/.env.example teamone-server-distr/config/.env
fi

For a deployment where SSL/TLS is managed directly by the TeamOne Proxy Server, use the HTTPS Nginx configuration template:

bash
if [ ! -f teamone-server-distr/config/default.conf ]; then
  sudo cp teamone-server-distr/config/nginx-https.conf.example teamone-server-distr/config/default.conf
fi

The nginx-https.conf.example template configures the TeamOne Proxy Server to receive HTTPS traffic, using TCP port 443 as the default listener port.

Step 4: Configure TeamOne ​

Review and update:

text
teamone-server-distr/config/.env

Configure the approved IBM Planning Analytics / TM1 hosts and, where applicable, the Cognos SSO gateway host.

See the full configuration reference:

TeamOne Proxy Server Configuration

Step 5: Install the SSL certificate and private key ​

Copy the SSL certificate and private key files to the current directory.

The expected filenames are:

text
teamone.crt
teamone.key

Copy them into the TeamOne Proxy Server certificate directory:

bash
sudo cp teamone.crt teamone-server-distr/cert/
sudo cp teamone.key teamone-server-distr/cert/

The certificate must be trusted by the users' devices and browsers.

A publicly trusted certificate, an internal CA-issued certificate, or a self-signed certificate may be used, provided the required trust is established on the users' devices.

Step 6: Load the Docker images ​

bash
sudo docker load -i teamone-server-distr/images/teamone-server-distr.tar
sudo docker load -i teamone-server-distr/images/teamone-nginx-distr.tar

Step 7: Start the TeamOne Proxy Server ​

bash
sudo docker-compose -f teamone-server-distr/docker-compose.yml up -d

Step 8: Verify the TeamOne Proxy Server ​

Open the configured TeamOne Proxy Server URL in a browser:

text
https://<teamone-proxy-fqdn>

Confirm that it displays:

text
TeamOne is up!

Step 9: Verify TM1 connectivity ​

After the TeamOne Proxy Server is running, confirm that it can reach an approved IBM Planning Analytics / TM1 REST API endpoint.

Example:

text
https://<teamone-proxy-fqdn>/?url=https://<tm1-host>:<tm1-rest-api-port>/api/v1/$metadata

If the TM1 REST API uses HTTP instead of HTTPS, use the corresponding http:// TM1 URL.

If the TeamOne Proxy Server is not starting, is not reachable, or cannot connect to IBM Planning Analytics / TM1, see:
